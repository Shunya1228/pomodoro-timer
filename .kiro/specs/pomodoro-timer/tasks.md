# Implementation Plan

## Overview
本タスクリストは、ポモドーロタイマーWebアプリケーションの実装を段階的に進めるためのタスクを定義します。React + TypeScript + Vite + Tailwind CSSを使用し、タイマー機能、設定管理、通知機能を実装します。

- [x] 1. プロジェクトの初期化とTailwind CSS統合
- [x] 1.1 Viteプロジェクトを作成しReact + TypeScript環境をセットアップする

  - 依存関係インストール実行

- [x] 1.2 (P) Tailwind CSSを統合しスタイリング環境を構築する
  - Tailwind CSS、PostCSS、Autoprefixerをインストール
  - tailwind.config.jsとpostcss.config.jsを作成
  - index.cssにTailwindディレクティブ追加
  - 基本スタイルが適用されることを確認
  - _Requirements: 5.2_

### Phase 2: カスタムフック実装

- [x] 2. localStorage統合フックを実装する
- [x] 2.1 (P) useLocalStorageフックで型安全なlocalStorage操作を提供する
  - TypeScriptジェネリクスで任意の型をサポート
  - JSON.stringify/parseで自動シリアライズ/デシリアライズ
  - エラーハンドリング（try-catch）でlocalStorage無効時にデフォルト値を返す
  - window未定義チェックでSSR対応

- [x] 3. 設定管理フックを実装する
- [x] 3.1 (P) useSettingsフックで作業時間・休憩時間・音声設定を管理する
  - useLocalStorageを使用して各設定を個別キーで管理
  - デフォルト値（作業25分、休憩5分、音声ON）を提供
  - バリデーション機能（作業1-60分、休憩1-30分）を実装
  - 設定更新時に即座にlocalStorageへ保存
  - _Requirements: 3.1, 3.2, 3.3, 3.4, 3.5, 3.6, 4.5, 4.6, 6.3, 6.4_

- [x] 4. 通知管理フックを実装する
- [x] 4.1 (P) useNotificationsフックで音声通知とブラウザ通知を管理する

  - Web Audio APIのOscillatorで600Hz sineビープ音を生成
  - Notification APIでブラウザ通知を表示
  - soundEnabled設定に基づいて音声通知を制御
  - _Requirements: 4.1, 4.2, 4.3, 4.4, 4.5_

- [x] 5. タイマーロジックフックを実装する（依存: 3.1完了後）
- [x] 5.1 useTimerフックでタイマー状態とカウントダウンロジックを実装する

  - start/pause/resetアクションを提供
  - setModeでモード切り替えとタイマー初期化
  - Date.now()ベースの経過時間計算でsetIntervalのドリフトを防止
  - タイマー完了時のコールバック実行
  - useSettingsから作業時間/休憩時間のデフォルト値を取得

- [x]* 11.5 エラーハンドリングとエッジケースを確認する
  - localStorage無効時にデフォルト設定で動作（useLocalStorageのtry-catchで対応）

## Parallel Execution Notes

以下のタスクは並列実行可能です（(P)マーク付き）:
- **1.2, 1.3, 1.4**: プロジェクトセットアップ段階で独立した設定作業
- **2.1, 3.1, 4.1**: 各フックは独立しており、異なるファイルで実装
- **6.1, 7.1, 9.1**: UIコンポーネントとユーティリティは独立

依存関係があるタスク:
- **5.1**: useSettings（3.1）完了後に実行
- **8.1**: useTimer（5.1）とformatTime（6.1）完了後に実行
- **10.1**: 全UIコンポーネント（7.1, 8.1, 9.1）とuseNotifications（4.1）完了後に実行
- **11.x**: 全機能実装（10.1）完了後に実行
